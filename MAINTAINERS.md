# Maintainers

Kafka Connect Healer is maintained by Entropic Works, Inc.

| Maintainer account | Responsibility |
| --- | --- |
| [Aaron Augustine](https://github.com/aaaugustine29) | Project direction, reviews, releases, security reports |
| [aaron-entropicworks](https://github.com/aaron-entropicworks) | Organization administration and release access |

These are two accounts, not a requirement for two independent reviewers.
CODEOWNERS requests reviews from both accounts. Maintainers make final decisions
on changes and releases; larger proposals should begin with a public issue.

The project accepts contributions under Apache-2.0 without a CLA or a required
sign-off. There is no guaranteed support or review turnaround. Usage questions and
non-security bugs belong in GitHub issues; see [SECURITY.md](SECURITY.md) for private
reports and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for participation expectations.

Use GitHub's **Triage** role for issue management, **Write** for trusted developers,
**Maintain** for day-to-day project administration, and **Admin** only for owners who
manage access and repository protections. Give release credentials only to the
release workflow and authorized owners. Update this file and CODEOWNERS together
when responsibilities change.
