# Maintainers

Kafka Connect Healer is maintained by Entropic Works, Inc.

| Maintainer account | Responsibility |
| --- | --- |
| [Aaron Augustine](https://github.com/aaaugustine29) | Project direction, reviews, releases, security reports |
| [aaron-entropicworks](https://github.com/aaron-entropicworks) | Project maintenance and releases |

Maintainers review contributions and coordinate releases. Larger proposals should
begin with a public issue.

The project accepts contributions under Apache-2.0 without a CLA or a required
sign-off. There is no guaranteed support or review turnaround. Usage questions and
non-security bugs belong in GitHub issues; see [SECURITY.md](SECURITY.md) for private
reports and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for participation expectations.
