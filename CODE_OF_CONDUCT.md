# Code of conduct

Kafka Connect Healer welcomes contributors of all backgrounds and experience levels.
Treat people with respect in issues, pull requests, reviews, and other project spaces.

Discuss ideas and code constructively. Give specific feedback, assume good intent,
accept corrections, and help newcomers understand the project. Disagreement is welcome;
personal attacks, harassment, discriminatory language, threats, sexual attention,
and publishing someone else's private information are not.

Maintainers may edit or remove inappropriate content and restrict participation
when needed. They will consider context and apply these expectations consistently.

To report a concern, ask a [maintainer](MAINTAINERS.md) for a private contact method.
If you use a public issue to request contact, omit incident details, names, and
private information. Security vulnerabilities use the separate channel in
[SECURITY.md](SECURITY.md).
